# Create the native fixed-effect binomial-logit adapter

Create the native fixed-effect binomial-logit adapter

## Usage

``` r
gt_glm_adapter(id = "glm", metadata = list())
```

## Arguments

- id:

  Adapter identifier.

- metadata:

  Descriptive metadata.

## Value

A logistic `gt_adapter` using stats::glm with 200 iterations.
